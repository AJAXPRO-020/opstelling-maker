# AGENTS.md

## Projectcontext

Dit is een kleine statische Ajax line-up maker met HTML, CSS en JavaScript.

## Werkwijze

1. Bekijk eerst de bestaande code voordat je iets wijzigt.
2. Maak vóór codewijzigingen een kort plan.
3. Werk in kleine stappen.
4. Stop na een grote wijziging zodat ik kan reviewen.
5. Houd de code simpel en begrijpelijk.
6. Voeg geen onnodige libraries toe.
7. Leg na afloop kort uit welke bestanden zijn aangepast.

## UI en UX

De gebruiker is zelf UX-designer geweest. Behandel designkeuzes daarom serieus.

Bij UI-werk:

1. Werk mobile first.
2. Zorg voor duidelijke visuele hiërarchie.
3. Gebruik goede spacing en alignment.
4. Gebruik bestaande styling waar mogelijk.
5. Maak geen generieke AI SaaS-look.
6. Gebruik geen random gradients, overdreven schaduwen of nutteloze animaties.
7. Voeg states toe waar logisch: hover, focus, disabled, empty en error.
8. Bouw rustig, overzichtelijk en onderhoudbaar.
